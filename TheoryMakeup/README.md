### Theory Makeup

#### Topics Covered:

##### HTML Forms

- Form submission with `<form>`, `action`, `method`, and `onsubmit`
- Form structure and grouping
    - `<fieldset>` and `<legend>`
    - `<label>` and matching `for`/`id` attributes
- Form controls
    - Text, number, email, and password inputs
    - Radio buttons, select menus, and options
    - Checkboxes, range inputs, and text areas
    - Submit and reset controls
- Input attributes
    - `name`, `placeholder`, `required`, and `minlength`
    - `min` and `max` for number inputs

##### JavaScript Form Validation

- Inline event handlers with `onkeyup` and `onsubmit`
- Selecting elements with `document.getElementById()`
- Reading input values and updating page content with `innerText`
- Validating email input, including checking a string suffix with `endsWith()`
- Displaying validation messages in the page
- Returning `false` to prevent form submission when validation fails
- Running code after the page content loads with `DOMContentLoaded`
